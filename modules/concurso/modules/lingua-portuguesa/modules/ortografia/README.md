## Quais as regras mais comuns de Siglas (e Acrônomos)?

<details>

<summary>RESPOSTA</summary>

<br/>

### Quando nós temos uma sigla com até 3 letras

A gramática oficial nos diz que quando nós temos uma sigla com até 3 letras, nós escrevemos todas as letras em maiúsculo.

- PR
- PRF
- ONU
- PUC

**Observação:**  
O plural das siglas acima será apenas adicionando um **"s"** no fim das siglas.

### Quando nós temos uma sigla com até 4 letras

⚠️ Se a sigla **FOR LIDA SEPARADAMENTE**, então todas as letras serão escritas com letra maiúscula:

- UFCG
- INSS
- IBGE

⚠️ Se a sigla **NÃO FOR LIDA SEPARADAMENTE** e sim `COMO UMA PALAVRA`, apenas a primeira letra será escritas com letra maiúscula:

- Uern

</details>

## O que são Prefixos e Pseudoprefixos?

<details>

<summary>RESPOSTA</summary>

<br/>

## 01 — Prefixo

Um **prefixo** é um elemento colocado **antes de uma palavra** para modificar ou acrescentar um significado a ela. Ele não costuma existir de forma independente com o mesmo significado que possui quando está unido à palavra.

| Prefixo               | Significado do prefixo                                 | Uso em uma palavra                                       |

| **Des-**              | Negação, oposição, afastamento ou ação contrária       | **desfazer**; **desleal**; **desmontar**                 |
| **In- / Im- / I-**    | Negação, privação ou ausência                          | **infeliz**; **impossível**; **ilegal**                  |
| **Re-**               | Repetição, novamente ou retorno                        | **refazer**; **reler**; **recomeçar**                    |
| **Pre- / Pré-**       | Anterioridade, antecipação                             | **prever**; **preconceito**; **pré-história**            |
| **Ante-**             | Anterioridade, posição anterior                        | **anteontem**; **antebraço**; **antever**                |
| **Anti-**             | Oposição, contrariedade                                | **antissocial**; **antibiótico**; **antidemocrático**    |
| **Super-**            | Superioridade, excesso ou posição acima                | **supermercado**; **superlotação**; **super-homem**      |

## Quais as regras mais comuns de utlização do hífen (-)?

<details>

<summary>RESPOSTA</summary>

<br/>


### 01 — Usa-se hífen quando a primeira palavra é um prefixo ou pseudoprefixo e a segunda começa com **H**

* **Super-homem**
* **Anti-higiênico**
* **Pré-história**
* **Sub-humano**
* **Extra-humano**
* **Contra-harmônico**
* **Co-herdeiro**
* **Circum-hospitalar**
* **Geo-história**
* **Semi-hospitalar**

**⚠️ Exceção:**  
> Com os prefixos **des-** e **in-**, o hífen não é usado quando o segundo elemento perde o **H** inicial.

* **Desumano**
* **Desumidificar**
* **Inábil**
* **Inumano**

### 02 — Usa-se hífen quando o prefixo termina com a mesma vogal que inicia a segunda palavra

* **Anti-inflamatório**
* **Anti-ibérico**
* **Contra-almirante**
* **Infra-assinado**
* **Infra-axilar**
* **Supra-auricular**
* **Auto-observação**
* **Eletro-ótica**
* **Micro-ondas**
* **Semi-interno**

> **⚠️ Exceção:**  
> O prefixo **co-** geralmente se junta à palavra seguinte, mesmo quando ela começa com **O**.

* **Coobrigação**
* **Coocupante**
* **Coordenar**
* **Cooperação**
* **Cooperar**

### 03 — Não se usa hífen quando o prefixo termina em vogal e a segunda palavra começa com vogal diferente

Quando o prefixo termina em uma vogal e a segunda palavra começa com **uma vogal diferente**, as duas partes normalmente são unidas sem hífen.

* **Antiaéreo**
* **Autoescola**
* **Autoestrada**
* **Autoaprendizagem**
* **Extraescolar**
* **Agroindustrial**
* **Aeroespacial**
* **Hidroelétrico**
* **Plurianual**
* **Coeducação**

**Observe a diferença:**

* **Micro-ondas** → mesma vogal: **o + o**
* **Microempresa** → vogais diferentes: **o + e**

### 04 — Não se usa hífen quando o prefixo termina em vogal e a segunda palavra começa com R ou S

Quando o segundo elemento começa com **R** ou **S**, não usamos hífen. Em vez disso, a consoante inicial é **duplicada**.

* **Antirreligioso**
* **Antirracista**
* **Antissocial**
* **Antissemitismo**
* **Contrarregra**
* **Contrassenso**
* **Extrarregular**
* **Infrassom**
* **Minissaia**
* **Microssistema**

Assim:

> **prefixo + R → RR**
> **prefixo + S → SS**

### 05 — Usa-se hífen com os prefixos circum- e pan- quando a segunda palavra começa com vogal, M ou N

* **Circum-escolar**
* **Circum-murado**
* **Circum-navegação**
* **Circum-hospitalar**
* **Pan-africano**
* **Pan-americano**
* **Pan-mágico**
* **Pan-negritude**
* **Pan-helênico**
* **Pan-hispânico**

### 06 — Usa-se hífen com hiper-, inter- e super- quando a segunda palavra começa com R

* **Hiper-requintado**
* **Hiper-realista**
* **Hiper-resistente**
* **Inter-racial**
* **Inter-regional**
* **Inter-relação**
* **Inter-resistente**
* **Super-racional**
* **Super-resistente**
* **Super-revista**

### 07 — Usa-se hífen com os prefixos ex-, sota-, soto-, vice- e vizo-

Os prefixos **ex-**, **sota-**, **soto-**, **vice-** e **vizo-** são escritos com hífen.

* **Ex-presidente**
* **Ex-aluno**
* **Ex-diretor**
* **Ex-reitor**
* **Sota-piloto**
* **Sota-mestre**
* **Soto-mestre**
* **Vice-presidente**
* **Vice-reitor**
* **Vizo-rei**

> **⚠️ Atenção:**  
> O prefixo **ex-** deve indicar uma condição anterior ou algo que deixou de ser.

* **Ex-presidente** → alguém que já foi presidente.
* **Ex-aluno** → alguém que já foi aluno.

### 08 — Usa-se hífen com pós-, pré- e pró- quando o segundo elemento mantém seu significado próprio

* **Pós-graduação**
* **Pós-operatório**
* **Pós-venda**
* **Pós-guerra**
* **Pré-natal**
* **Pré-escolar**
* **Pré-história**
* **Pré-operatório**
* **Pró-europeu**
* **Pró-africano**

> **⚠️ Atenção:**  
> Quando essas formas deixam de funcionar como prefixos autônomos, não se usa hífen.

* **Pospor**
* **Prever**
* **Promover**

### Hífen em palavras compostas

Além dos prefixos, o hífen também aparece em **palavras compostas**, isto é, palavras formadas pela união de dois ou mais elementos que mantêm uma relação de significado.

### 09 — Usa-se hífen em palavras compostas por justaposição

Quando duas ou mais palavras se unem para formar uma nova palavra e **mantêm sua estrutura e significado próprios**, normalmente usamos o hífen.

* **Arco-íris**
* **Ano-luz**
* **Decreto-lei**
* **Médico-cirurgião**
* **Tenente-coronel**
* **Guarda-chuva**
* **Guarda-noturno**
* **Amor-perfeito**
* **Primeiro-ministro**
* **Conta-gotas**

> **⚠️ Exceção:**  
> Algumas palavras que originalmente eram compostas perderam, com o tempo, a percepção de que eram formadas por dois elementos. Nesses casos, escrevem-se **sem hífen**.

* **Girassol**
* **Madressilva**
* **Mandachuva**
* **Pontapé**
* **Paraquedas**
* **Paraquedista**

### 10 — Usa-se hífen em nomes de espécies botânicas e zoológicas

* **Couve-flor**
* **Erva-doce**
* **Feijão-verde**
* **Abóbora-menina**
* **Bênção-de-deus**
* **Andorinha-grande**
* **Cobra-capelo**
* **Formiga-branca**
* **Andorinha-do-mar**
* **Bem-te-vi**

### 11 — Usa-se hífen em ALGUNS nomes de lugares compostos

O hífen é utilizado em determinados **topônimos** — nomes próprios de lugares — especialmente aqueles iniciados por **grã**, **grão** ou **formas verbais**, além de alguns casos em que os elementos estão ligados por artigo.

* **Grã-Bretanha**
* **Grão-Pará**
* **Abre-Campo**
* **Passa-Quatro**
* **Quebra-Costas**
* **Quebra-Dentes**
* **Traga-Mouros**
* **Trinca-Fortes**
* **Albergaria-a-Velha**
* **Montemor-o-Novo**

> **⚠️ Exceção:**  
> A maioria dos nomes de lugares compostos não utiliza hífen.

* **América do Sul**
* **Belo Horizonte**
* **Cabo Verde**
* **Castelo Branco**

> **Exceção consagrada pelo uso:** `Guiné-Bissau`.

### 12 — Usa-se hífen em algumas locuções consagradas pelo uso

Em regra, **não se usa hífen em locuções**, ou seja, expressões formadas por duas ou mais palavras. Entretanto, algumas expressões tradicionalmente consagradas mantêm o hífen.

* **Água-de-colônia**
* **Arco-da-velha**
* **Cor-de-rosa**
* **Mais-que-perfeito**
* **Pé-de-meia**
* **Ao deus-dará**
* **À queima-roupa**
* **Mato-grossense**
* **À-toa**
* **Mão-de-obra**

A regra geral é escrever as locuções **sem hífen**, salvo as exceções consagradas pelo uso.

### 13 — Usa-se hífen com bem- e mal- em determinadas palavras

Os advérbios **bem** e **mal** podem receber hífen quando formam uma unidade de sentido com a palavra seguinte, especialmente quando esta começa por **vogal** ou **H**.

* **Bem-aventurado**
* **Bem-estar**
* **Bem-humorado**
* **Mal-afortunado**
* **Mal-estar**
* **Mal-humorado**
* **Bem-criado**
* **Bem-ditoso**
* **Bem-falante**
* **Bem-nascido**

> **⚠️ Atenção:**  
> Em algumas palavras, **bem** e **mal** aparecem aglutinados, sem hífen:

* **Benfeito**
* **Benfeitor**
* **Benquerença**
* **Benfazejo**
* **Malcriado**
* **Malfeito**

### Hífen com verbos e pronomes

### 14 — Usa-se hífen na ênclise

A **ênclise** ocorre quando um pronome pessoal oblíquo aparece **depois do verbo**. Nesse caso, o hífen liga o verbo ao pronome.

* **Diga-me**
* **Conte-me**
* **Ajude-me**
* **Entregou-me**
* **Chamou-o**
* **Encontrou-a**
* **Faça-o**
* **Veja-se**
* **Mostre-nos**
* **Explique-lhes**

### 15 — Não se usa hífen nas formas do verbo haver acompanhadas de de

Quando usamos o verbo **haver** seguido da preposição **de**, não usamos hífen.

* **Hei de estudar**
* **Hás de conseguir**
* **Há de melhorar**
* **Havemos de vencer**
* **Haveis de aprender**
* **Hão de chegar**
* **Hei de trabalhar**
* **Hás de entender**
* **Havemos de encontrar**
* **Hão de resolver**

Portanto:

❌ **Hei-de estudar**
✅ **Hei de estudar**

A regra está expressamente prevista na Base XVII do Acordo Ortográfico.

</details>

## Qual a diferença de Conselho x Concelho?

<details>

<summary>RESPOSTA</summary>

<br/>

### **1. Conselho** ✅

Com **s**, significa **opinião, recomendação, orientação** ou um **órgão colegiado**.

| Frase                                                                        | Justificativa                                                                                              |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **O Conselho Municipal de Saúde aprovou a proposta.**                        | **Conselho** é um órgão colegiado responsável por deliberar, fiscalizar ou acompanhar ações.               |
| **O servidor recebeu um conselho do superior.**                              | **Conselho** significa **orientação ou recomendação**.                                                     |
| **O Conselho Tutelar encaminhou o caso ao Ministério Público.**              | **Conselho** designa um órgão composto por conselheiros.                                                   |
| **O candidato deve consultar o Conselho de Administração antes da decisão.** | **Conselho** refere-se a um **órgão colegiado**, e não a uma divisão territorial.                          |
| **O Conselho Municipal de Educação publicou uma resolução.**                 | **Conselho** é uma instituição colegiada que exerce funções administrativas, consultivas ou deliberativas. |

### **2. Concelho** ✅

Com **c**, é uma palavra usada principalmente em **Portugal** para designar uma **divisão administrativa territorial**, equivalente, de modo geral, ao que chamamos de **município** no Brasil.

| Frase                                                           | Justificativa                                                                                                    |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Lisboa é a sede do concelho de Lisboa.**                      | **Concelho** designa uma **divisão administrativa de Portugal**.                                                 |
| **O concelho de Sintra possui várias freguesias.**              | **Concelho** é uma unidade territorial portuguesa, equivalente, de forma aproximada, ao **município** no Brasil. |
| **A população do concelho participou das eleições municipais.** | **Concelho** refere-se ao território administrativo português, não a um órgão colegiado.                         |
| **O município está localizado no concelho de Braga.**           | **Concelho** indica uma **circunscrição administrativa portuguesa**.                                             |
| **As autoridades do concelho anunciaram novas medidas.**        | **Concelho** está sendo usado no sentido de **divisão territorial/administrativa de Portugal**.                  |

### **Macete para concurso**

> **CONSELHO → órgão ou orientação**
> **CONCELHO → território administrativo português**

Assim, se a questão falar de **Conselho Municipal, Conselho Tutelar, Conselho de Administração ou conselho como recomendação**, é **CONSELHO**. Se estiver falando de uma **divisão administrativa de Portugal**, é **CONCELHO**.

<div id="secao-sessao-cessao"></div>

## Qual a diferença de Seção (ou secção), sessão, e cessão?


<details>

<summary>RESPOSTA</summary>

<br/>

### **Seção (ou secção) — com Ç**

**Seção** significa uma **divisão, parte ou departamento** de algo. No português do Brasil, a grafia usual é **seção**; **secção** é uma variante legítima, especialmente usada em Portugal.

| Frase                                                                | Justificativa                                                                              |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **O documento foi encaminhado à seção de Recursos Humanos.**         | **Seção** indica um **departamento ou setor** dentro de uma instituição.                   |
| **Consulte a seção de legislação do edital.**                        | **Seção** indica uma **parte ou divisão** de um documento.                                 |
| **O candidato deve preencher a seção referente aos dados pessoais.** | **Seção** é uma divisão específica dentro de um formulário.                                |
| **A seção eleitoral do candidato foi alterada.**                     | **Seção** indica uma divisão administrativa utilizada para organizar os locais de votação. |
| **O relatório possui uma seção específica sobre licitações.**        | **Seção** indica uma **parte ou divisão temática** de um documento.                        |

> **Macete:** se puder substituir por **“parte”, “setor”, “divisão” ou “departamento”**, use **seção**.

### **Sessão — com SS**

**Sessão** com dois "ss" é o **período de duração** de uma atividade, reunião, espetáculo ou trabalho.

| Frase                                                               | Justificativa                                                                                  |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **A sessão do Conselho Municipal de Saúde começará às 9 horas.**    | **Sessão** indica o período em que uma reunião ou atividade acontece.                          |
| **O juiz encerrou a sessão após ouvir as testemunhas.**             | Trata-se do período de realização de uma atividade formal, neste caso, uma atividade judicial. |
| **A Câmara Municipal realizou uma sessão extraordinária.**          | **Sessão** é o período em que os membros de um órgão se reúnem para deliberar.                 |
| **A sessão de votação foi suspensa por falta de quórum.**           | **Sessão** refere-se ao período destinado à realização da votação.                             |
| **O candidato participou da sessão de treinamento antes da prova.** | **Sessão** indica um período específico dedicado a determinada atividade.                      |

> **Macete:** se você puder substituir por **“reunião”, “período” ou “encontro”**, provavelmente será **sessão**.

### **Cessão — com C**

**Cessão** significa o ato de **ceder, transferir ou disponibilizar** algo para outra pessoa ou entidade.

| Frase                                                                         | Justificativa                                                                           |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **O servidor foi colocado à disposição por meio de cessão para outro órgão.** | **Cessão** significa a **transferência/disponibilização** do servidor para outro órgão. |
| **A cessão do imóvel foi autorizada pela administração pública.**             | **Cessão** indica o ato de **ceder o uso ou direito** sobre algo.                       |
| **O contrato prevê a cessão dos direitos autorais à empresa.**                | **Cessão** significa a **transferência de direitos** de uma pessoa para outra.          |
| **A cessão de uso do espaço público dependerá de autorização.**               | **Cessão** indica a transferência ou concessão do **direito de uso**.                   |
| **A cessão do crédito foi formalizada por contrato.**                         | **Cessão** significa a **transferência de um direito**, neste caso, um crédito.         |

> **Macete:** se a ideia for **“ceder”, “transferir”, “passar para outra pessoa” ou “dar o direito de uso”**, use **cessão**.

### **Resumo para concurso**

| Palavra    | Ideia principal                               | Macete                        |
| ---------- | --------------------------------------------- | ----------------------------- |
| **Seção**  | Parte, divisão ou setor                       | **Seção = divisão/setor**     |
| **Secção** | Variante de **seção**, mais comum em Portugal | **Secção = seção**            |
| **Sessão** | Período de uma atividade ou reunião           | **Sessão = reunião/período**  |
| **Cessão** | Ato de ceder ou transferir                    | **Cessão = ceder/transferir** |

**Observação:**  
Essas três palavras são **homófonas**, ou seja, possuem a mesma pronúncia ou pronúncia muito semelhante, mas apresentam **grafias e significados diferentes**.

</details>
